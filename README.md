# Demo de protección de rama

Repositorio temporal para comprobar reglas de GitHub Actions sobre `master`.

- Un PR documental debe pasar el check obligatorio `check de CI`.
- Un PR que agregue el archivo `FAIL_CI` debe fallarlo y quedar bloqueado por
  la regla de protección.
- No contiene el código, la documentación ni los datos de TP1–TP6.

Prueba temporal de un PR documental verde.
